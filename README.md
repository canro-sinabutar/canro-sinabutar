# Hi, I'm Canro Sinabutar

**Senior SDET and QA Automation Architect** · Tangerang, Indonesia

I have spent 14+ years building test automation for web, mobile and API platforms in fintech, e-commerce and
food delivery. I design automation frameworks from scratch, run them in CI/CD, and build agentic AI tooling that
writes, runs and repairs tests.

## What I do

- **API automation at scale:** REST API frameworks in Java with Cucumber/BDD and REST Assured, running in Jenkins
  pipelines across distributed microservices.
- **Web and mobile automation:** Playwright (TypeScript), Cypress, Selenium, and Appium for iOS and Android.
- **Agentic AI for testing:** TypeScript and Python agents on local LLMs (Ollama, Llama 3.2 Vision, Qwen) that
  observe the app, act, check the result, and regenerate broken tests.
- **Performance testing:** distributed load and stress suites with JMeter and Locust.
- **Quality leadership:** mentoring manual QA engineers into SDET roles, writing QA handbooks, and reproducing
  production incidents to shorten MTTR.

## Highlights

- **40% improvement in product reliability** at Delivery Hero (Tabsquare.ai), after building REST API automation
  frameworks from scratch with Jenkins CI/CD.
- **Zero critical defects at go-live** on mission-critical ERP and fintech modules (GoPayLater, OVO, Bizzy
  Marketplace).
- **Agentic AI testing:** built an agentic framework for autonomous web and mobile state validation, and a Python
  engine with an Observe, Think, Act, Reflect loop that heals failing API tests.
- **Developer tooling:** co-developed an agentic AI CLI at Tabsquare that generates test suites, and built a
  cross-platform runner that executes one TypeScript script on both iOS and Android.
